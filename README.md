## 我在坚持的几件事

- **每天一个 commit。** 进度可以慢，但不能断。
- **每个项目都必须真的上线。** "在我电脑上能跑"不算完成，公开链接才算。
- **把卡住的地方写下来。** 报错、判断失误、走过的弯路，都留在日志里而不是删掉。
- **先砍范围，再动手。** 一个做完的小东西，胜过十个没做完的大东西。
